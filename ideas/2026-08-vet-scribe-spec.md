# Ветеринарный AI-скрайб: спека и честный вердикт

Дата разбора: 2026-08-13
Идея: приём у вета (питомец + хозяин) → запись → транскрибация (Whisper/медSTT) →
LLM собирает медкарту в формате SOAP → вет заверяет и вставляет в свою систему.
Профиль: узкая задача широкой профессии, ядро — коммодити-модель, платит профессионал.

---

## ГЛАВНЫЙ ВЕРДИКТ (читать первым)

**Пространство подтверждено по всем осям — боль, WTP, экономика, регуляторика, сборка,
приём денег все зелёные. НО рынок созревает быстрее, чем хотелось: «ещё один скрайб для
мелких животных в US/UK» — уже поздно.** Соло-вход есть только через **узкий защищаемый
клин** (неанглийский язык ЕС, недообслуженный вид, или спец-воркфлоу), потому что
широкий companion-animal рынок уже забирают фонды и — главное — **нативные скрайбы внутри
PIMS** (ezyVet/IDEXX, Provet, Instinct, Shepherd) коммодитизируют standalone-продукты.

## Что зелёное (фундамент)

- **Боль:** 30–40% времени на записи, 1–3 ч/день «pajama time», ~50% выгорания. Топ
  решаемая жалоба.
- **WTP:** живой рынок, сладкая точка $79–150/вет, бесплатный тир — стандартная воронка.
- **Экономика:** LTV ~$3000+ (отток ~2%/мес, живут 4–5 лет), CAC <$100 через SEO/сообщества
  → LTV:CAC уверенно 3:1+.
- **Регуляторика лёгкая:** HIPAA нет (животные). RCVS требует ручного заверения ветом →
  позиционируем как «черновик, заверяемый ветом» (режет ответственность). GDPR: хозяин —
  субъект данных, нужно согласие; **EU-хостинг — преимущество** против US-игроков.
- **Сборка соло-подъёмна, 3–4 мес.** COGS $0.10–0.18/приём → маржа 55–85%.
- **Деньги снимаются:** финское юрлицо + Stripe собирает с US/UK/AU/CA/EU.

## Клин (единственный жизнеспособный вход)

Инкумбенты оптимизируют **US/UK-English + мелкие животные + US-PIMS**. Открыто:
1. **Неанглийский язык ЕС** — немецкий/французский/нордик/нидерландский. 328k ветов ЕС,
   покрытие инкумбентов near-zero → **языковой моат + EU-резидентность данных**. Меньше TAM,
   но защищаемо и совпадает с твоей ЕС-базой. Требует оперировать в этом языке (SEO/саппорт).
2. **Недообслуженный вид** (английский рынок) — **кони, экзотика/птицы, крупный скот**.
   Шаблоны и воркфлоу отличаются, инкумбенты их игнорят. Оперируешь по-английски.
3. Спец-воркфлоу (дентал, шелтер, ER) — уже, но занято меньше.

Гонка по цене (тир бесплатный у Scribenote) — слабый клин, туда не лезть.

## MVP-спека

- **Сегмент клина:** выбрать 1 (язык ЕС / вид). НЕ дженерик small-animal GP.
- **Выход:** SOAP-заметка (Subjective/Objective/Assessment/Plan), шаблоны под тип визита.
- **Интеграция:** **copy-paste MVP жив и монетизируется** (так заходили все). PIMS-запись
  (Cornerstone/ezyVet) — fast-follow под удержание, не входной билет.
- **Стек:** Next.js (web, desktop+mobile-браузер) · MediaRecorder API · **Deepgram Nova-3
  Medical + список вет-терминов** (Whisper один = только демо, 13% ошибок на препаратах) ·
  LLM в строгую JSON-схему SOAP · Postgres/Supabase + аудит · Stripe · S3/R2.
- **Безопасность = продукт:** дозы НЕ считать самому (verbatim + флаг «не указано»),
  диаризация против путаницы «кто сказал», гейт на числа, трассировка «транскрипт→заметка»,
  быстрый инлайн-эдит. 31% галлюцинаций в ambient-заметках — твой продукт это и есть
  workflow снижения ошибок, а не вызов LLM.
- **Цена:** ~$79–99/вет/мес + бесплатный тир (N заметок/мес) как воронка.
- **Пилот:** 3–5 живых ветов на реальном аудио — обязателен до запуска.

## GTM

- **Канал: SEO-сравнения** («X vs Y», «free plan», «vet SOAP note AI») + **сообщества**
  (VIN, r/veterinary, FB-группы) + **бесплатный тир** для сарафана. Веты — тесная реферальная
  профессия. Холодный контекст — supplement, не канал.
- Конференции (VMX/BSAVA/London Vet Show) — дорого для соло, сначала ходить, не стоять.

## Риски
1. **Окно закрывается** — заходить быстро и узко, не в дженерик.
2. **PIMS бандлят нативный AI** — главный коммодитизатор; клин должен быть там, где PIMS
   слаб (неанглийский язык, редкий вид).
3. **Доверие к точности** — единственный настоящий моат и единственный источник оттока.

## Открытое решение
Какой клин — **язык ЕС** (моат языка+данных, оперируешь в языке) или **вид** (кони/экзотика,
оперируешь по-английски)? От этого зависит вся спека и GTM.
